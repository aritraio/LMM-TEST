# 🌊 LMM-TEST: Water Ripple Simulation Benchmark

A comprehensive performance and logic benchmark for Large Multimodal Models (LMMs), focusing on their ability to generate complex, real-time physics simulations using the HTML5 Canvas API.

## 🎯 The Challenge

The objective of this test is to evaluate how different state-of-the-art models handle a multi-faceted engineering task:

1.  **Physics Accuracy**: Implementing a 2D finite-difference wave equation with damping and interference.
2.  **Performance Optimization**: Managing a 500x500 grid at 60 FPS using double buffering and efficient memory management.
3.  **Interaction Design**: Supporting multi-touch and mouse inputs for real-time energy injection.
4.  **Architectural Integrity**: Maintaining a clean separation between simulation logic, rendering, and input handling.

## 🛠️ Requirements & prompt

The full technical specification used for these tests can be found in `prompt.txt`. It mandates:
- **Canvas 2D API** (No WebGL)
- **Finite Difference Approximation** for wave propagation
- **Double Buffering** for grid state management
- **Modular JavaScript Architecture**

## 🚀 How to Run

1. Navigate to any model folder (e.g., `sonnet 4.6/`).
2. Open the contained `.html` file in any modern web browser.
3. Click or touch the screen to interact with the water ripples.
